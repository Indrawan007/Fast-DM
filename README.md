# Fast-DM

Fast-DM adalah aplikasi Download Manager untuk Linux dengan dukungan browser extension untuk mempermudah pengiriman tautan unduh ke aplikasi.

## Download
👉 https://github.com/Indrawan007/Fast-DM/releases/tag/v.1.2.0

## Release Files
- `fast-dm_1.2.0_amd64.deb` — aplikasi Linux
- `fast-dm-extension-v1.2.0.zip` — browser extension

## Instalasi

### Linux App
```bash
sudo apt install ./fast-dm_1.2.0_amd64.deb
